# 核心链路支持私有化离线运行

POC 的最终网络区位尚未确定，且无人机位置、图像、线索和事件属于受控业务数据。四条核心链路必须能够在单套私有环境中运行且不依赖公网，同时不预先绑定互联网、政务外网、公安内网或现场独立环境；公网地图、云端模型和厂商云服务只能作为可替换增强项，不能成为核心演示的必要条件或接收未脱敏业务数据。

## Considered Options

- 公有云优先：交付较快，但依赖现场公网连通性，并带来业务数据出域风险。
- 立即绑定某一内网环境：能够针对性集成，但在网络区位尚未确定时会造成过早锁定和返工。
- 私有化离线基线、环境适配后置：增加本地地图、模型和部署封装成本，但能在环境未定时保持核心链路可验证。

## Consequences

- 态势展示必须支持离线或内网地图服务。
- 智能查询优先使用本地或内网模型；临时公网模型不得接收坐标、图像或事件明细。
- 无人机厂商接入和最终网络区位通过适配边界后续确定，不纳入 POC 的多厂商兼容承诺。
